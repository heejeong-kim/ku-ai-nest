건강·질환·장내환경 데이터를 맞춤식이 정기구독과 연결

누적 진단 데이터 12만 건+정기구독 식이솔루션 29만 건+2024 TIPS R&D 선정

Platum, 프레쉬아워 TIPS R&D 선정(2024)

고객문제

건강상태·질환·장내환경에 맞는 식이와 영양제품을 보호자가 스스로 판단하기 어려움

접근방식

AI 질환 진단 모델, 반려동물 빅데이터, 장내 미생물 분석을 맞춤 식이·영양 정기구독으로 연결

학습 포인트

AI 사용보다 사용할수록 데이터가 쌓여 결과 품질과 재구매 구조가 좋아지는가가 핵심

판단 기준

반복 사용 데이터가 개인화 품질을 높이고 재구매 구조를 만드는지 확인

우리 프로젝트 적용점

5.1 MVP AI 기능 설계 시 입력·처리·출력이 반복 데이터 축적과 다음 결과 품질 개선으로 연결되는지 확인

CASE STUDY · FAILURE 1/4

워키도기 ‘도그마스터’ — 반려견 훈련 앱

기술개발·R&D 수행과 사업 지속성은 별도 검증

확인된 사실
도그마스터
2024.12 폐업

2016년 설립, 강아지 훈련 앱 운영, 머신러닝·챗봇·비대면 관련 국가 R&D 수행 이력 확인

THE VC, 워키도기

주의

공개자료만으로 폐업 원인을 수익성 부족 또는 문제 검증 실패로 단정 불가

검토 질문

온라인 훈련만으로 효과를 느꼈는가, 무료 콘텐츠·오프라인 훈련사 대비 지불 이유가 분명했는가

학습 포인트

기술개발이나 정부 R&D 수행 자체가 실제 지불·재사용·운영구조를 보장하지 않음

위험요인

전문가 개입이 필요한 문제를 앱만으로 해결하려는 범위 설정 위험

우리 프로젝트 적용점

MVP가 온라인·앱만으로 완결되는 문제인지, 전문가 개입이나 오프라인 요소가 필요한 문제인지 먼저 구분

CASE STUDY · FAILURE 2/4

앵그리펫츠 — IP 결합 펫 커머스

화제성 높은 IP와 반복구매 구조는 별도 문제

확인된 사실
앵그리펫츠
2023.05 폐업

2021년 설립, 샌드박스네트워크·이경규 앵그리독스 IP와 결합한 반려동물 커머스로 출발, 운영기간 약 1.6년

THE VC, 앵그리펫츠

주의

짧은 존속기간이 곧 IP 마케팅 실패를 의미하지는 않음

검토 질문

유명인 IP가 반복구매로 이어졌는가, IP 화제성과 커머스 상품력이 분리되어 있지는 않았는가

학습 포인트

초기 유입은 만들 수 있어도 반복사용·재구매 구조가 없으면 지속성으로 이어지기 어려움

위험요인

이벤트·콘텐츠 의존형 유입이 핵심 가치나 제품력보다 앞서는 구조

우리 프로젝트 적용점

초기 고객 유입이 특정 이벤트·채널에 의존하는지, 반복 방문을 만드는 구조인지 1.1 사용 상황에서 점검

CASE STUDY · FAILURE 3/4

이에쓰씨컴퍼니 ‘올라펫’ — 펫푸드 유통 플랫폼

장기 운영과 투자유치 이력도 장기 지속성을 보장하지 않음

확인된 사실
올라펫
2023.06 폐업

영국·스웨덴 프리미엄 펫푸드 브랜드 국내 독점 유통, Series A 투자유치, 10.9년 운영 후 폐업 확인

THE VC, 이에쓰씨컴퍼니

주의

장기간 운영과 투자유치 이력이 있어도 초기 생존이 장기 지속성을 보장하지 않음

검토 질문

해외 브랜드 독점유통 구조가 국내 경쟁사 진입 시 방어 가능한 차별점이었는가

학습 포인트

얼마나 오래 운영했는가보다 현재도 구조적으로 지속 가능한가가 중요

위험요인

유통 마진 구조와 경쟁 심화에 대한 방어력 부족 가능성

우리 프로젝트 적용점

1.3 경쟁사 분석에서 우리의 차별점이 경쟁사가 쉽게 복제할 수 있는 요소인지, 시간이 지나도 방어 가능한 구조인지 확인

CASE STUDY · FAILURE 4/4

펫그라운드 — 반려동물 체지방 측정기기

기술개발보다 유통·가격·반복사용 구조를 먼저 검증

확인된 사실
펫그라운드
2025.07 폐업

2023년 설립, 반려동물 체지방 측정기기 개발, 2024년 관련 국가 R&D 수행 이력 확인

THE VC, 펫그라운드

주의

국가 R&D 수행 이력이 있었다는 사실만으로 상용화·매출 성과를 단정할 수 없음

검토 질문

초기 제조·재고 비용을 회수할 가격·판매 구조였는가, 단일 기능이 반복 사용을 만들었는가

학습 포인트

헬스케어·진단 분야는 기술 개발뿐 아니라 실제 유통·가격·반복사용 구조를 초기에 검증해야 함

위험요인

하드웨어·진단 요소가 MVP 검증 전에 제조비와 규제 부담을 키울 가능성

우리 프로젝트 적용점

하드웨어·진단 요소가 필요한 아이디어라면 초기 제조·재고 비용 없이 검증 가능한 최소 형태로 축소

0. 펫 산업 특강

  • 최신 산업 데이터와 주요 시장 변화를 확인할 것
  • 최근 스타트업·서비스 사례를 통해 주요 기회영역을 살펴볼 것
  • 성장·좌초 사례와 진입조건을 통해 사업성 판단 기준을 이해할 것
  • 이후 시장조사에 활용할 신뢰 가능한 데이터 출처를 확인할 것

1. 시장·트렌드·경쟁사 분석

  • 펫 시장의 현황과 주요 트렌드를 공식자료와 신뢰 가능한 자료를 통해 확인할 것
  • 경쟁 서비스의 고객, 핵심 기능, 가격, 강점, 약점을 동일 기준으로 비교할 것
  • 단순히 시장이 큰 분야가 아니라 해결되지 않은 문제가 존재하는 영역을 탐색할 것

2. 공식데이터 기반 고객 니즈·페인포인트 검증

  • 통계청, 농림축산식품부, 관련 공공기관의 자료를 우선 활용할 것
  • 개인 경험이나 추측보다 반복적으로 관찰되는 불편과 미충족 니즈를 근거로 사용할 것
  • 발견한 문제마다 출처, 수치, 조사연도, 대상 집단을 함께 기록할 것

3. 최종 아이템 확정·가치제안

  • 공식데이터로 검증한 최종 핵심 페인포인트 1개를 기준으로 아이템을 구체화할 것
  • 핵심 고객과 사용 상황을 유지하면서 최종 사업 아이템 1개를 확정할 것
  • 고객에게 제공하는 결과를 한 문장의 가치제안으로 표현할 것

4. 사업계획서 핵심항목·초안 작성

  • 문제, 솔루션, 타겟, 비즈니스모델을 하나의 논리 흐름으로 연결할 것
  • 주장마다 데이터 근거 또는 고객 근거를 배치할 것

5. AI 기반 서비스 콘셉트·웹 MVP 구현

  • 핵심 가설 검증에 필요한 MVP 범위와 유저 플로우를 먼저 확정할 것
  • AI가 실제 고객문제 해결에 담당할 역할을 1개 이상 정의할 것
  • PRD를 기준으로 AI 기능이 실제 작동하는 웹 MVP를 구현할 것

6. 최종 산출물 정리·제출

  • 1~5단계 결과를 하나의 사업 아이템 흐름으로 연결할 것
  • 사업계획서, AI 기반 웹 MVP, 주요 근거와 검증 결과를 하나의 제출 패키지로 구성할 것
  • MVP 링크와 선택적으로 연결한 Google Sheets 데이터 저장 작동 여부를 확인할 것

시장·트렌드·경쟁사 분석

1.1 아이디어·시장 구조화

  • 공통과정에서 정리한 아이디어를 검증 대상으로 사용할 것
  • 시장 규모보다 고객문제와 최근 시장 트렌드를 먼저 확인할 것
  • 아이디어가 속한 펫 세부시장과 직접·간접 경쟁환경을 함께 조사할 것
Claude 프롬프트공통과정 아이디어를 고객문제와 시장 기준으로 구조화해줘

1.2 시장·트렌드 조사

  • 공식자료와 신뢰도 높은 최신 자료를 우선 사용할 것
  • 시장규모, 성장 요인, 소비 변화, 반복되는 고객문제를 함께 확인할 것
  • 수치에는 조사연도와 출처를 함께 기록할 것
Claude 프롬프트공식자료와 신뢰도 높은 자료를 우선 사용해 입력 시장의 현황과 반복되는 고객문제를 조사해줘

1.3 경쟁 서비스 분석

  • 같은 고객문제를 해결하는 직접 경쟁과 간접 대안을 함께 찾을 것
  • 고객, 핵심 기능, 가격, 강점, 약점을 동일 기준으로 비교할 것
  • 경쟁사가 제공하지 못하는 틈새가 실제 고객문제와 연결되는지 확인할 것
Claude 프롬프트같은 고객문제를 해결하는 직접·간접 대안을 함께 비교해줘
실습 결과물
시장·트렌드 근거, 경쟁 서비스 비교표, 페인포인트 후보 3개, 다음 단계 복사용 요약
2

공식데이터 기반 고객 니즈·페인포인트 검증

  • 앞 단계의 다음 단계 복사용 요약 전체를 그대로 입력할 것
  • 입력된 페인포인트 후보 3개를 검증 대상으로 사용할 것
  • 새로운 페인포인트를 다시 발굴하지 않고 각 후보의 존재 여부, 문제 규모, 빈도, 영향받는 고객, 비용·시간·불안 등 손실을 공식데이터로 확인할 것
  • 후보마다 문제의 존재와 크기를 설명할 수 있는 공식통계 또는 공공데이터를 찾을 것
  • 공식데이터의 대상 기준이 핵심 고객 정의와 다르면 더 명확한 근거를 기준으로 고객을 보정하고 변경 이유를 기록할 것
Claude 프롬프트새로운 문제를 만들지 말고 입력된 페인포인트 후보가 공식데이터에서도 확인되는지 검증해줘
데이터 검증수치·대상·연도·출처를 비교하고 문제의 존재와 크기를 확인
팀 판단후보별로 채택 / 보류 / 제외를 결정하고 이유를 기록
실습 결과물
후보별 검증 결과, 팀 판단과 이유, 최종 핵심 페인포인트 1개, 다음 단계 복사용 요약

최종 아이템 확정·가치제안

  • 앞 단계의 다음 단계 복사용 요약 전체를 그대로 입력할 것
  • 공식데이터로 검증된 최종 핵심 페인포인트 1개를 기준으로 최종 아이템을 구체화할 것
  • 새로운 문제를 다시 찾거나 여러 아이템을 점수평가하지 않을 것
  • 핵심 고객, 사용 상황, 핵심 페인포인트, 경쟁분석 근거, 공식데이터 근거가 하나의 아이템으로 연결되도록 할 것
  • 해결방법은 핵심 문제를 직접 해결하는 수준으로만 정의하고 기능을 과도하게 확장하지 않을 것
Claude 프롬프트검증된 고객문제와 근거를 바꾸지 말고 최종 아이템 1개와 가치제안으로 구체화해줘
